01

环境准备与配置

Global install · Private registry address

通过 npm 全局安装 CLI；若使用私有或自建 registry，需通过环境变量 SKILLHUB_REGISTRY 指定服务地址，三种终端的设置方式各不相同。

全局安装 CLI —— 安装后即可使用 skillhub 命令
$npm install -g @astron-team/skillhub
Linux / macOS —— 通过环境变量设置 Registry
$export SKILLHUB_REGISTRY=https://skillhub.example.com
Windows PowerShell —— 设置环境变量
PS>$env:SKILLHUB_REGISTRY="https://skillhub.example.com"
Windows CMD —— 设置环境变量
>set SKILLHUB_REGISTRY=https://skillhub.example.com
!
PowerShell 与 CMD 的环境变量仅对当前会话生效，新开终端需重新设置；如需长期生效，请写入系统环境变量或使用 setx。
02

身份认证

Login · Identity · Logout

发布技能、删除远程技能等写操作需要鉴权；检索与本地安装通常无需登录。若未设置 SKILLHUB_REGISTRY 环境变量，可在 login 时用 --registry 一并指定服务地址。

使用 Token 登录 —— sk_xxx 替换为实际令牌
$skillhub login --token sk_xxx
登录并指定 Registry —— 免去配置环境变量，直连指定服务地址
$skillhub login --token sk_xxx --registry https://skill.xfyun.cn
查看当前登录身份
$skillhub whoami
退出登录 —— 清除本地凭据
$skillhub logout
03

技能检索

Search · Pagination · JSON output

支持关键字模糊搜索；--json 与 --limit 组合可用于脚本化批量拉取技能清单。

按关键字搜索技能
$skillhub search weather
分页拉取并以 JSON 输出 —— 空关键字匹配全部；适合接入自动化流程
$skillhub search "" --limit 50 --json
04

安装技能

Auto-detect · Multi-agent · Version / namespace / directory

默认自动探测本机已安装的 Agent 目录并写入；也可显式指定目标 Agent、版本、命名空间或自定义目录。

安装到自动探测的 Agent 目录 —— 最常用形式
$skillhub install pdf-parser
一次安装到多个 Agent —— --agent 可重复使用
$skillhub install weather --agent codex --agent claude-code
指定版本安装
$skillhub install pdf-parser --version 1.2.0
为裸 slug 指定命名空间 —— 解决同名技能归属歧义
$skillhub install pdf-parser --namespace myspace
安装到自定义目录
$skillhub install pdf-parser --dir ~/.claude/skills
强制覆盖已存在的安装 —— 也是升级单包的快捷方式
$skillhub install pdf-parser --force
i
优先级提示：显式 --dir 优先于 --agent 自动探测；若同一 slug 在多个 namespace 中存在，建议始终带上 --namespace 以确保安装来源唯一。
05

查看与更新

Listing · Bulk update · Overwrite strategy

批量更新已安装技能；若某个包更新失败或需强制替换，可用 --force 或「先删后装」两种等效方式处理。

查看已安装技能列表
$skillhub list
执行更新 —— 更新全部已安装技能
$skillhub update
方式 A：使用 --force 覆盖安装
$skillhub install pdf-parser --force
方式 B：先删除再安装 —— 与方式 A 效果等价，清理更彻底
$skillhub remove pdf-parser skillhub install pdf-parser
06

发布与移除

Publish to remote · Local remove · Remote delete

发布时需指定命名空间与可见性；移除操作默认作用于本地，加上 --remote 才会删除远程技能（需鉴权并二次确认）。

发布本地技能目录 —— 指定命名空间与可见性
$skillhub publish ./bear-showdoc --namespace development-center --visibility private
裸 slug 移除 —— 删除所有 namespace 中的同名本地安装
$skillhub remove pdf-parser
精确移除本地指定命名空间的技能
$skillhub remove pdf-parser --namespace myspace
删除远程技能 —— 需要认证，会弹出确认提示
$skillhub remove bear-showdoc --remote --namespace development-center
!
高危操作：remove --remote 会从 registry 永久删除技能，且不带 --namespace 的裸 slug 移除会波及所有命名空间的同名本地安装，执行前请务必确认。

参数速查

Common flags at a glance

下表汇总了各子命令支持的关键参数及适用范围。

Flag适用命令说明
--tokenlogin指定认证令牌，格式为 sk_xxx
--registrylogin指定 registry 服务地址，优先于 SKILLHUB_REGISTRY 环境变量
--limitsearch分页大小，配合空关键字可拉取全量清单
--jsonsearch以 JSON 结构化输出，便于脚本解析
--agentinstall指定目标 Agent，可重复使用以安装到多处
--versioninstall锁定安装版本，如 1.2.0
--namespaceinstall / remove / publish命名空间，用于消除同名技能歧义
--dirinstall自定义安装目录，优先于自动探测
--forceinstall强制覆盖已存在的安装
--visibilitypublish可见性，如 private / public
--remoteremove作用于远程 registry，需鉴权并二次确认
